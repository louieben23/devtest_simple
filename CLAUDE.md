# Claude Coding Instructions

## Code Quality

- Keep the code readable
- Do not overcomplicate the code
- Do not introduce type errors or any errors
- Use comprehensive variable names

## Components

- Create components if necessary

## UI Consistency

- Keep the UI the same as the other UI implementation

## API Requests

- For every API request, use the `useAPI` hook

## Security

- Do not inject any authentication tokens or login credentials in the code
- Use environment variables instead

## Changelog

- Create a `Changelog.md` entry for every change made, even if it's a small change
- Changelog should follow versions, what file is updated and added, what are the bug fixes
- Follow the format of the previous entries in the `Changelog.md` file
